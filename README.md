# Music Festival

Web aplikacija za pregled i upravljanje muzičkim festivalima.

## O projektu

Aplikacija omogućava posetiocima, izvođačima, organizatorima i administratorima da pregledaju i upravljaju sadržajem vezanim za muzičke festivale.

## Funkcionalnosti

- pregled muzičkih festivala
- pretraga festivala i filtriranje po žanru
- pregled scena i izvođača
- korisnički profili
- registracija i prijava korisnika
- različite korisničke uloge: posetilac, izvođač, organizator i administrator
- dodavanje i izmena festivala
- ocenjivanje i komentarisanje sadržaja
- omiljeni festivali
- ankete i prikaz rezultata
- sistem obaveštenja
- chat između korisnika
- beleženje statistike

## Tehnologije

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap i Font Awesome

## Pokretanje projekta lokalno

### Zahtevi

- WampServer ili XAMPP
- PHP
- MySQL
- web pregledač

## Baza podataka

SQL dump sa lokalnim korisničkim podacima nije deo javnog repozitorijuma iz bezbednosnih razloga. Za pokretanje projekta potrebno je obezbediti sopstvenu bazu i strukturu tabela.

## Struktura projekta

- `core/` - osnovne PHP funkcije, skripte i povezivanje sa bazom
- `css/` - CSS stilovi
- `includes/` - delovi stranica i pomoćne PHP skripte
- `javascript/` - JavaScript fajlovi
- `Slike/` - slike i grafički resursi
- PHP fajlovi u glavnom direktorijumu - stranice aplikacije

## Napomena

Projekat je razvijen za lokalno pokretanje u WampServer/XAMPP okruženju.
